# Onimusha: Way of the Sword

## Setup

1. Select Onimusha in HappyCheats. With the game closed, choose **Install / update**.
2. Choose **Launch game**, load gameplay, and wait for the trainer to report ready.
3. Keep HappyCheats running with Onimusha selected.

The trainer provides **unlimited health (F1)**, **auto-parry (F2)**, **one-hit stun (F3)** and **stun immunity (F4)**. Auto-parry remains experimental.

Open the shared menu with **Ctrl+Del**, or enable **Xbox shortcuts**, hold **Menu (☰) for 350 ms**, then tap **RB**. Use mouse and keyboard for the shared menu, in windowed or borderless mode. **F6** toggles Onimusha's native status panel; **Insert** opens REFramework.

Existing controller shortcuts: hold Menu for 350 ms, then tap D-pad **up / right / down / left** for the four combat toggles above, or **LB** to disable all. No game-specific controller profile is needed for Menu+RB.

See [shared menu instructions](in-game-menu.md), [compatibility and protocol details](onimusha-protocol.md), and [validation records](validation.md). This documentation update adds no gameplay or physical-controller validation.
