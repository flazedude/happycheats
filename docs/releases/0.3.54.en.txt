HappyCheats 0.3.54 — two LAN hosts and GitHub updates

Official clients check JACK-PC at 192.168.2.76:17845, GPD-PC at 192.168.2.59:17845, then GitHub. Every source is checked, and the newest trusted release is selected. An older reachable LAN feed no longer hides a newer GitHub release. Downloads prefer a matching package from the first LAN, then the second LAN, then GitHub. Alternate sources must independently verify the same release version, size and SHA-256. Connection failures can try another source; signature, channel, metadata and package-integrity failures stop the operation. Conflicting packages with the same version are rejected.

Known official LAN-only, LAN-plus-GitHub and GitHub-only settings adopt the bundled three-source list only when their trusted signing identity and channel match. The preserved settings file is not rewritten. Custom endpoints and custom feed lists remain unchanged, and existing custom configurations without a feed list keep their previous fallback behavior.

Both development PCs share one GitHub repository and the original signing identity while keeping their authentication, keys and LAN configuration local. Release work stays on separate task branches before integration into main; the shared GitHub lock permits only one publisher at a time. Each publishing PC mirrors the same verified release bytes to its local LAN. Signed mirror metadata and host-specific feed assets let peers refresh from GitHub using only the public key. Automatic refresh runs at server startup and five minutes after each completed attempt once enabled locally; a running web server alone does not synchronize releases or install client updates.

Both complete distributions contain all seventeen trainer payloads, the updater and runtimes, including Dawnwalker 0.4.1 and Phantom Blade Zero 0.1.1. This release changes update discovery and distribution; trainer behavior and the shared Ctrl+Del and Menu+RB controls are unchanged.

Validation covers offline multi-source selection, stale and unavailable sources, matching-package fallback, trusted configuration migration and mirror verification. Hosted feeds, package hashes and packaged-client startup are checked during publication. The original PC's automatic mirror refresh still requires local installation and verification; successful local HTTP access does not prove access from another PC. Gameplay and physical-controller behavior are not newly validated by this release.
