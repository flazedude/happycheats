HappyCheats 0.3.65 — 独立修改器更新

- 在游戏库排序旁新增“更新”，打开独立的中英双语逐游戏修改器更新窗口。
- 每款游戏拥有独立的软件包版本，初始为 1.0.0。兼容的游戏修复及新增游戏无需替换 HappyCheats EXE，也无需变更客户端版本。
- 签名软件包包含该游戏的模块逻辑与修改器文件。下载后关闭支持的游戏，重新加载修改器库，再按需点击对应游戏的“安装 / 更新”。
- 客户端更新保持独立；需要新版客户端的修改器会提示版本要求，不强制升级。
- 增加 GitHub / 局域网签名目录、不可变游戏软件包发布、对等主机镜像、兼容性检查、损坏修复及统一菜单回归检查。
- 保留现有修改器和 Ctrl+Del / 按住 Menu 350 毫秒再按 RB 的统一菜单。控件保持可点击，忙碌及失败信息记录在本地。
- 验证使用签名合成软件包、离线测试及 WPF / HTTP 检查。未启动游戏，不声称已验证游戏效果、实体手柄或离线对等主机的部署。
