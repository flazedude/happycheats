《红色沙漠》修改器 0.2.6 适配已下载的 Charting the Unknown 更新：Steam 构建 26317560、程序版本 1.0.0.3424。已更新精确程序、钩子及布局校验；其他版本会被拒绝。请关闭游戏后选择“安装 / 更新”，再连接新版修改器。

资源恢复现在通过游戏状态元数据确认资源身份，不再依赖旧数字别名。当前数据中的旧别名 25/26 指向装备项，因此不会再被当作体力或精神力。状态引用按实际的 16 位宽度读取；生命、体力、精神力与呼吸值及装备数据分开识别。

移动及标记功能要求普通客户端角色类型、当前本地用户、本地控制标志、控制对象反向引用和完整生命属性链均匹配。身份变化会关闭功能并取消待执行传送。当前版本仅接受已验证的玩家类型标记 1；其他主角及类型尚未确认，功能可能不可用。传送保留外层移动更新后的写入顺序和后续位置观察，不提供地面安全落点或场景加载验证。

验证范围：只读程序与基础/DLC 资源分析、精确绑定检查、原生钩子/重定位/身份/资源/传送模拟测试、客户端及共享菜单/控制器回归测试，以及完整发行包验证。游戏始终关闭，未读取运行中游戏内存、注入、启用作弊或修改存档。真实游戏效果、DLC 水下行为、实体控制器及独占全屏仍未验证。无限道具使用仍不可用。

两种完整发行包均包含全部十七款修改器及重新构建的《红色沙漠》载荷。Ctrl+Del，以及按住 Menu 350 毫秒后轻按 RB，仍用于切换共享菜单。签名更新保留 JACK-PC 局域网、GPD-PC 局域网及 GitHub 三个来源，并沿用原有签名身份。
