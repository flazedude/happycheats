Keep the Witcher page open for continuous effects. Refills stop after the script's six-second client lease expires. Currency and progression additions may persist in normal saves; disabling the trainer does not undo them.

Adds the game to the bilingual library with Steam artwork. Both the signed LAN update and complete standalone EXE contain the same new trainer payload.
Installation generates a mod override from the exact verified local vanilla script, leaving original game files unchanged. It rejects conflicting r4game.ws mods and preserves foreign or edited files. Removal uses an ownership receipt and retains changed files. Close the game before Install / update or Remove trainer.
Commands use a session-bound, expiring mailbox, duplicate-request protection, and script acknowledgements. Unsupported builds and stale status cannot issue commands.

Validation scope: offline C# protocol and installer fixtures, existing project regression suites, script API checks against installed game source and read-only native I/O inspection, payload checks, and packaged-client smoke checks. WitcherScript is compiled by the game at startup; no offline game script compiler is installed. Game startup, actual script compilation, in-game bridge behavior, cheat effects, save behavior and second-PC LAN connectivity are NOT gameplay-verified. The game was not launched and its saves were not changed during development.
