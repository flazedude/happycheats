HappyCheats 0.3.54 — 双局域网主机与 GitHub 更新

官方客户端依次检查 JACK-PC（192.168.2.76:17845）、GPD-PC（192.168.2.59:17845）和 GitHub。每个源都会检查，并选择可信的最新版本。可连接但过时的局域网源不再遮蔽 GitHub 上的新版本。下载优先使用第一台局域网主机，然后是第二台，最后是 GitHub；备用源必须独立验证相同的版本、大小和 SHA-256。连接失败可尝试其他源，签名、通道、元数据或安装包完整性校验失败则停止操作。同版本但内容不同的安装包会被拒绝。

已知官方的单局域网、局域网加 GitHub、单 GitHub 配置，仅在可信签名身份和通道匹配时采用内置的三个更新源。保留的设置文件不会被改写。自定义地址和自定义更新源列表保持不变；没有列表的现有自定义配置继续使用原来的备用源逻辑。

两台开发电脑共用同一 GitHub 仓库和原签名身份，各自保存登录凭据、私钥与局域网配置。每项工作使用独立分支，完成后合入 main；共享 GitHub 锁确保同时只有一台电脑发布。每台发布电脑将已验证的同一套发行文件镜像到本机局域网。带签名的镜像元数据和各主机更新源文件，使另一台电脑仅用公钥即可从 GitHub 刷新镜像。本地启用后，会在服务器启动时刷新，并在每次结束五分钟后再次尝试；仅运行网页服务器不会同步发行文件或安装客户端更新。

两种完整分发格式包含全部十七款游戏修改器、更新程序及运行库，包括《黎明行者之血》0.4.1 和《影之刃零》0.1.1。本次修改更新发现与分发流程，修改器行为以及 Ctrl+Del 和 Menu+RB 统一菜单操作保持不变。

验证范围包括离线多源版本选择、过时或不可用的源、安装包一致性备用下载、可信配置迁移和镜像校验。托管更新源、安装包哈希及完整客户端启动会在发布时检查。原电脑的自动镜像刷新仍需在当地安装并验证；本机 HTTP 可访问不能证明另一台电脑能够连接。本次发行不增加实战或实体手柄验证结论。
