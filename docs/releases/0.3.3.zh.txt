HappyCheats 0.3.3

- 在星露谷物语修改器中内置官方 SMAPI 4.5.2 安装包，以及对应源代码、许可证和分发声明。
- 点击“安装 / 更新”，即可在需要时安装内置 SMAPI，然后安装 HappyCheats 模组，安装过程无需另行下载。
- 已有兼容的 SMAPI 4.5.2 及以上版本时直接复用。保留不完整或无法识别的安装，并显示修复提示。
- 通过 SMAPI 启动星露谷物语。“移除修改器”仍会保留 SMAPI 和其他模组。
- 保留 0.3.2 的紧凑单行布局、同行操作控件和鼠标悬停说明。
- 将客户端、单文件启动程序和更新程序的发行版本统一为 0.3.3。

从 HappyCheats-0.3.3-win-x64-single-exe.zip 中解压 HappyCheats.exe 后运行。单个 EXE 包含完整发行内容及 SMAPI，另附 SHA-256 校验文件。现有设置和已解压客户端的在线更新会保留。完整目录 ZIP 仍可用于在线更新。

星露谷物语需要 Windows Steam 版 1.6.15 及以上的 1.6 系列版本。安装或更新前请关闭游戏，之后启动并载入单人存档。游戏模块版本与修改功能不变。实际游戏启动和游玩效果仍待验证。
