HappyCheats 0.3.34 — 修复巫师 3 指令连接

巫师 3 修改器 0.1.1 将指令与连接文件放入 content/content0/happycheats_witcher3。游戏的 LoadCSVDirect 从这个实际内容目录读取文件，之前的模组内容目录无法通过该接口读取。安装程序兼容旧的文件归属记录，并保留其他游戏文件。

点击功能后立即写入指令，不再先等待前台窗口及新心跳。切回 HappyCheats 后也能正常接收游戏确认；同一游戏进程暂停时，状态不会再因四秒超时而失效。可用按钮保持正常的“开启 / 关闭”文字，等待中的指令显示“已排队”。每条指令只发送一次，游戏无法读取指令文件时会给出明确的修复提示。

请关闭巫师 3，在新版客户端中点击一次“安装 / 更新”以安装 0.1.1，然后自行启动游戏并载入杰洛特存档。持续效果需要保持巫师页面打开；切换窗口导致游戏暂停时，返回实际游玩即可处理排队指令。

验证仅覆盖受影响的指令流程、巫师界面、安装迁移、载荷与发行包启动检查。带签名的局域网更新及独立 EXE 均包含此次修复。指令路径依据本机游戏原生代码分析确定；修复后的实时指令确认和作弊效果仍待游戏内验证。测试未启动游戏或打开存档。
