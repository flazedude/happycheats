HappyCheats 0.3.55

HappyCheats 启动后及运行期间定期检查更新，并在后台自动下载。新版本仍须通过签名、更新通道、大小、SHA-256 和完整安装包验证，才会提示安装。

打开“客户端更新”可查看实时下载进度和更新日志，同时继续使用修改器主窗口及现有快捷键。关闭后重新打开更新窗口会继续显示同一次下载及已验证的安装包。下载就绪后，非阻塞提示提供“重启并安装”和“稍后”；只有您主动选择安装且支持的游戏已关闭后，才会开始安装。

客户端检查 JACK-PC 局域网、GPD-PC 局域网和 GitHub 上的最新可信版本，并优先使用内容完全一致的局域网安装包。全部十七款随附修改器保持不变。

验证范围：离线签名更新源、下载、取消、重试及安装程序回归测试；WPF 非模态窗口、进度恢复、重启提示、运行中游戏拦截及共享键盘/控制器路径测试。未验证真实游戏效果、实体控制器或独占全屏。退出 HappyCheats 会取消尚未完成的下载；选择“稍后”会在本次客户端运行期间保留已就绪的安装包。
