HappyCheats 0.3.46 — 局域网优先，GitHub 备用更新

检查更新时优先使用已配置的局域网服务器；请求失败或超时后，自动检查公开的 GitHub 发行版。局域网安装包下载失败或停滞时，仅在验证 GitHub 签名信息中的版本、文件大小与 SHA-256 完全一致后，才重新下载。签名、更新通道或完整性错误不会绕过验证；取消操作不会触发备用下载。

现有局域网客户端需要先在局域网可用时更新到此版本，之后即可使用备用地址。原有受信任设置和签名密钥保持不变，仅在配置信息匹配时从随包默认配置补充备用地址。也可运行新版完整独立 EXE。旧客户端在获得新代码前无法使用备用更新。

发行流程会将相同的完整安装包发布到局域网和 flazedude/happycheats 的 GitHub Releases，并同步对应源代码提交和新版独立 EXE。共享的 AGENTS.md 要求所有聊天窗口在完成功能修改后使用此流程。修改器沿用已发布的 0.3.45 版本，包括红色沙漠 0.2.5。

验证涵盖模拟网络可用性、超时、取消、传输失败、签名与安装包拒绝、配置迁移和发行暂存。实际托管下载及打包客户端验证结果单独记录。这些检查不启动游戏或修改存档，也不代表已验证第二台电脑连接或实际游戏效果。
