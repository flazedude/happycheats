HappyCheats 0.3.7

- 将应用内字母标志替换为已生成的金属蓝色手柄与扳手图标。
- 为游戏库中的全部六款游戏加入真实游戏图标，并在所选游戏的横幅中显示官方游戏标志。两种发行包均内置素材，可离线显示。
- 窗口自动适配显示器可用区域，支持最低 800 x 480 逻辑像素的 Windows 掌机布局。较窄窗口将功能说明与操作控件分行显示，保持文字可读。
- 游戏库、修改器页面、状态消息和客户端更新页面支持手指上下滑动，同时保留鼠标滚轮与滚动条操作。按钮与数值输入框的最小触控高度提升至 44 像素。
- 更新页面整体可滚动，在较矮屏幕上仍可访问操作按钮；紧凑布局直接显示完整功能说明。

验证范围：离线自动测试、桌面及掌机逻辑尺寸下的中英文布局渲染、打包单文件客户端预览，以及局域网签名更新源和下载包 / EXE 校验。尚未实测掌机触屏手势、另一台电脑的连接或实际游戏效果。本版仅调整客户端界面，修改器载荷未变更；未启动游戏或修改存档。
