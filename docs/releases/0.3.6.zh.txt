HappyCheats 0.3.6

- 新增《黎明行者之血》实验性模块，支持 Windows Steam 版本 25232147：持续恢复生命、耐力与血量，以及一次性补满生命与耐力。
- 使用反射确认的游戏原生资源方法定期补满数值。这不是无敌，单次致命伤害仍可能导致死亡。持续功能默认关闭，切换角色或世界后自动关闭。
- 补满血条时，游戏原生方法也会修复受损血量格；这些变化可能随正常存档保存。
- 新增 Dawnwalker Xbox 手柄快捷键：按住 Menu 后，方向键上 / 右 / 下 / 左分别控制生命 / 耐力 / 一次性恢复 / 血量；LB 全部关闭，RB 显示或隐藏悬浮面板。保留现有鬼武者手柄配置。
- 新增不会抢占游戏焦点的悬浮面板，支持窗口或无边框模式，按 F6 或 Menu+RB 切换。请保持 HappyCheats 运行并选中 Dawnwalker。
- 局域网签名更新与完整单文件 EXE 均包含新 UE4SS / Lua 模块，安装时校验游戏版本、文件归属及命令会话。
- 已调查地图标记传送：发行版的 DebugTeleportPlayer 方法仅为空实现，因此本版不提供传送按钮。

验证范围为已安装游戏的只读检查、离线运行时 / 协议 / 安装器 / 手柄检查及打包客户端界面检查。尚未验证游戏加载器启动、实际游玩效果、实体手柄操作或另一台电脑的连接。请先关闭 Dawnwalker，再选择“安装 / 更新”，然后启动并载入存档。本次工作未修改游戏存档，也未启动游戏。
