HappyCheats 0.3.37 — 艾尔登法环离线资源修改器

新增 Steam《艾尔登法环》（应用 ID 1245620），带签名的局域网更新与完整独立 EXE 均包含修改器 0.1.0。四项实验性功能：定期补满生命、专注值和精力（F1–F3），以及一次恢复全部资源（F4）；F12 关闭全部持续补满。补满生命并非无敌，致命伤害仍可导致死亡。不编辑资源上限、卢恩、物品或属性。

提供明确的连接 / 断开操作、直接离线启动、中英文界面，以及仅作用于已连接游戏或 HappyCheats 的快捷键。切换页面、断开连接、角色变化或轮询会话失效会清除所有开关。修改器设置不改动游戏文件或存档。离线启动仅设置子进程的 Steam 应用身份，不更改受保护启动器或 Easy Anti-Cheat 文件。

初始配置面向 App Ver. 1.17.1（全球版 Windows 程序版本 2.7.1.0），依据持续维护的模组源代码布局；拒绝其他版本。写入前必须通过程序版本、内存特征、存活的本地角色及明确离线状态检查。运行中的反作弊 / 受保护启动器、联网状态和检测到的无缝联机均被拒绝。不隐藏、禁用、修补或卸载反作弊组件。仅限离线单人使用，不保证以后联网时的账号安全。

验证范围：隔离内存与会话逻辑测试、过期会话和拒绝条件测试、界面检查、完整打包检查与带签名的服务器下载校验。本机已登记的 Steam 游戏库中未安装本游戏；开发期间未启动游戏或改动存档。实际游戏效果、游戏电脑上的启动以及第二台电脑的局域网连接仍待验证。安装步骤与限制见 docs/elden-ring.md。
