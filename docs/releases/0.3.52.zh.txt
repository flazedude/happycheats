HappyCheats 0.3.52 — 仅使用 GitHub 更新

官方客户端现在直接检查 GitHub Releases。用户下载更新时，发布电脑无需保持开机。局域网发布已弃用；正常发布命令使用原有签名密钥，仅向 GitHub 发布带签名的完整更新包和独立 EXE。

两台已配置的开发电脑均可向同一仓库发布。本机发布配置会先用线上签名更新源验证原有签名身份，再导入密钥。开始工作前获取并整合最新源代码，完成后提交并推送。仓库级 GitHub 发布锁防止两台电脑同时上传或完成发布；版本、源代码和不可覆盖的文件校验仍然保留。私钥与凭据绝不通过源代码仓库同步。

保留的官方局域网设置仅在公钥与更新通道匹配内置默认设置时迁移到 GitHub。自定义更新地址、备用地址及其他签名身份保持不变。更新仍须通过签名、通道、大小、SHA-256 和压缩包结构校验。0.3.46 起的客户端可在局域网服务停止时通过已有 GitHub 备用地址取得本次更新；更早版本请运行一次新版完整独立 EXE。

完整发行包包含全部十七款游戏的修改器，并包含此前已提交的影之刃零 0.1.1 启动修复及黎明行者之血 0.4.1 伤害启用修复。请关闭相关游戏后选择“安装 / 更新”，以应用这些修改器修复。本次更新未新增修改器控制项。

验证范围包括离线更新迁移、安全与安装测试、发布流程检查、客户端及统一菜单和手柄回归测试，以及重新构建的黎明行者与影之刃零载荷检查。发行验证还包括完整客户端冒烟检查及线上签名、下载和哈希检查。更新验证不启动游戏或改动存档；实际游戏效果、实体手柄及另一台电脑的访问仍未验证。
