HappyCheats 0.3.53 — 多电脑协作与 GitHub 更新

将两台开发电脑的改动合并为同一套完整发行包。官方客户端直接使用 GitHub 签名更新；原官方局域网配置仅在可信公钥和通道匹配时迁移。自定义更新地址和签名身份保持不变。下载不再依赖发布电脑一直开机。

包含支持 Steam 构建 25915545 / 补丁 3 的《黎明行者之血》修改器 0.4.1。超级伤害允许基础值为零但实际倍率有效的属性，请求 10 倍实际倍率并验证成功后才报告启用；验证失败时只恢复仍由本修改器控制的改动。对已加载角色的只读检查确认了基础值为零、实际值为正的情况；实际战斗伤害仍未验证。同时包含《影之刃零》0.1.1 的加载器启动修正。

两台配置完成的电脑可使用各自的 GitHub 登录和原签名密钥的私有副本，在同一仓库开发与发布。每项工作使用独立分支，完成后合入 main。发布会检查已整合的源代码和预留版本，并通过共享 GitHub 锁阻止同时发布。仅 GitHub 的发布设置忽略无关的旧局域网配置，拒绝将私钥文件误作公钥，并在恢复中断发布时从已验证的暂存文件还原完整分发文件。

两种完整分发格式均包含全部十七款游戏的修改器、更新程序和运行库。请先关闭相关游戏，再选择“安装 / 更新”应用修改器修正；仅更新客户端不会替换游戏目录中的文件。Ctrl+Del 和 Menu+RB 统一菜单操作保持不变。

验证包括离线更新迁移、安全校验、发布协作、安装器、客户端、统一菜单和手柄逻辑测试，以及重新构建的黎明行者和影之刃零载荷与完整安装包检查。托管签名、下载、哈希和打包客户端启动检查会在发布时进行。实际游戏效果和实体手柄仍未验证；发布验证不会启动游戏或修改存档。
