HappyCheats 0.3.51 — 黎明行者伤害功能修正

将《黎明行者之血》修改器更新至 0.4.1，支持 Steam 构建 25915545 / 补丁 3。超级伤害现在同时读取原生伤害属性的基础值与计算后的实际值；当实际攻击倍率有效时，基础值为零不会再直接导致拒绝。修改器请求 10 倍实际倍率并验证结果；如果其他效果、数值限制或写入失败导致无法确认，则有条件地恢复仍由本修改器控制的改动。实际值为零的未启用攻击类型保持不变。

伤害错误现在会指出缺失接口或失败属性，并在操作后保留于诊断信息中。关闭时只恢复仍由本修改器控制的属性，保留游戏后续产生的变化。所有功能初始关闭。Ctrl+Del、按住 Menu 350 毫秒后点按 RB，以及现有直接快捷键保持原有统一菜单行为。

请先关闭游戏，打开新版完整 EXE，选择“安装 / 更新”后再启动游戏。仅更新客户端不会替换已安装的游戏修改器。两种完整分发格式均包含全部十七款游戏，以及源代码版本 0.3.50 中的影之刃零加载器修正。

验证包括受支持游戏程序的静态检查、模拟原生属性行为的离线测试、回滚与恢复、客户端、安装器、统一菜单、手柄逻辑和安装包检查。实际战斗伤害、实体手柄操作及另一台电脑访问仍未验证。这是本机准备的构建；局域网与 GitHub 签名发布仍需原发布电脑和原有签名密钥。
