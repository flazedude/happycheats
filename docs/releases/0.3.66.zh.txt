HappyCheats 0.3.66 — 修改器版本警告

当游戏模块报告兼容性、运行时不匹配或已安装的修改器文件需要更新、存在更新的签名修改器包，或下载后的修改器尚需重新加载时，游戏库侧栏将在对应游戏旁显示红色 !。普通未连接或等待心跳不会触发版本警告。将鼠标移到标记上可查看原因。

点击 ! 仅打开该游戏的修改器更新页面，提供“检查此游戏更新”及对应的更新 / 修复操作。排序旁的“更新”仍显示所有游戏，客户端更新保持独立。客户端启动时、每 30 分钟及手动请求时，验证两台局域网主机和 GitHub 上的现有签名目录。检查不会自动下载修改器。

下载完成后，警告会保留至加载新版本。请关闭支持的游戏、点击“重新加载修改器库”，随后按需点击对应游戏的“安装 / 更新”。尚无更新并不表示不受支持的游戏版本已兼容；更新页面会说明后续步骤，不承诺已有修复。

修改器载荷、各游戏软件包版本和共享模块接口均未改变。本次共享界面更新需要一次完整客户端升级，包含新的完整独立 EXE。

验证范围：离线 / 合成签名包、按游戏筛选、警告及重新加载状态、忙碌与错误处理，以及中英文和深浅主题的 WPF 检查。未启动游戏、修改存档、测试实体手柄或声称已验证游戏效果。
