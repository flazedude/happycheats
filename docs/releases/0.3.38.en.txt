HappyCheats 0.3.38 — Astroneer compatibility and shared in-game menu

Updates Astroneer trainer to 0.2.0 for the inspected 1.44.4 executable, Steam build 25119744. Retains the previous 1.43.2.0 profile, rejects uninspected executable hashes, reports the detected version/build accurately, and rechecks the executable before reading trainer status. Session-checked Disable all remains available while a connected game is loading. The 10× / 20× collection choices, oxygen, backpack power and byte controls retain their existing behavior.

Fixes a reproduced oxygen/power restoration edge case: re-enabling after a failed restore first restores the original value, rather than capturing a modified value as the new baseline. A persistent restore failure keeps the toggle off and reports the failure.

Adds a shared Ctrl+Home companion menu for registered games and future modules, using each game's feature definitions for toggles, actions, choices and numeric inputs. Astroneer collection selection reflects the game's confirmed rate and does not automatically enable collection. Keep HappyCheats running and use windowed or borderless mode; exclusive fullscreen is unsupported by this companion menu. Existing game shortcuts remain available.

Close Astroneer, update HappyCheats, then select Astroneer and choose Install / update before launching. Both the signed LAN update and the complete standalone EXE include the updated trainer and shared menu.
