## GTA V Enhanced remains blocked

Installed Steam build **25971420**, file **1.0.1158.16**, SHA-256 `b48e80f5fc899eb89e5dcc9f3b68e9551cc8dcfac78b2a940b207e569e9987ea` differs from the reviewed executable. Both `.text` sections have approximately 7.99 bits/byte entropy, and all five source-backend signatures have zero disk matches. This packed image does not provide enough static evidence to authorize the existing native bindings. The [official Script Hook V release](https://www.dev-c.com/gtav/scripthookv/) still lists Enhanced **1.0.1158.13**, so it cannot substitute for this .16 backend. Its executable gate and installed files are preserved. No GTA package is presented as a compatibility fix. Further work requires independently verified current unpacked binding evidence; a version-string or hash-only exception would not establish compatibility.

## Validation and distribution

Use the existing Library Update operation with each affected game closed. Installer ownership, signed cache verification and explicit Connect behavior remain unchanged. The shared GameOverlay, Ctrl+Del and Menu held 350 ms + RB path remain unchanged. English/Chinese notes accompany every independent package. Existing client and published archives are not rebuilt.

All validation is static, offline or synthetic. It does not establish live hook installation, gameplay, terrain landing, physical-controller behavior, exclusive fullscreen or execution on GPD-PC. JACK-PC's signed catalog matched GitHub before publication; GPD-PC's feed timed out during preflight and has no current verified state in this task.
