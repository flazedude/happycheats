# Project Hospital loader notices

This payload includes the official BepInEx 5.4.23.5 Windows x64 distribution and its bundled HarmonyX, Harmony interop, Mono.Cecil, MonoMod and UnityDoorstop components. Corresponding license texts and the UnityDoorstop v4.5.0 source archive are provided in this directory. Their pinned upstream resources are recorded in `third-party-resources.json`.

The trainer's JSON transport uses only the game's existing core .NET 3.5 libraries and has no additional JSON-library dependency.

Game assemblies are used only as local compile-time references and for read-only compatibility inspection. No game assembly or game data is distributed in this payload.
